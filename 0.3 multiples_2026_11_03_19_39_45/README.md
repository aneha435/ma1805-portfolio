Project overview- For my third coding project, I created a colourful pattern of repeated circles using p5.js. The aim was to explore repetition through coding and understand how loops and arrays can be used to generate visual patterns.
The sketch consists of circles arranged in rows and columns with different colours distributed across the canvas.
Technical development- I used loops controls the horizontal positioning, while the other controls the vertical positioning. This allowed me to generate multiple circles without manually writing the code for each individual shape.
I created an array containing different RGB colour values. Using the random () function, I selected colours from this array and applied them to the circles.
The noLoop() function prevents the sketch from continuously redrawing, allowing the pattern to remain static.
Creative Decisions- I chose a selection of pastel colours, including pink, purple,yellow,green and blue, to create a bright and playful design.
I arranged the circles in evenly spaced rows and columns to make the repetition visually clear.
The random selection of colours adds variation to the pattern, meaning that different arrangements can be generated using the same code.
User interaction can be used through Mouse clicks which creates a colourful visual pattern. Using mousePressed() function alongside redraw() allows viewers to engage with the design rather than simply observe a static image.
